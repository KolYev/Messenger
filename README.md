# Messenger

Простой TCP-сервер на C++ с использованием Winsock2.

## Описание

Сервер создаёт сокет, привязывается к порту 4000 на всех сетевых интерфейсах, принимает одно входящее TCP-подключение и выводит полученное сообщение в консоль.

## Сборка

Открой `Messenger.slnx` в Visual Studio 2022 и собери решение (F7). Проект использует платформу x64.

## Использование

1. Запусти сервер.
2. Подключись клиентом (например, telnet) к `127.0.0.1:4000`.
3. Отправь сообщение размеров меньше 1024 байт — оно отобразится в консоли сервера.

## Требования

- Windows 10+
- Visual Studio 2022 (v145 toolset)
- C++20
